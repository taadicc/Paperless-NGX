# Paperless NGX Desktop Client

A C# WPF desktop application developed to interact with Paperless NGX through its REST API and present document-related information in a graphical user interface.

## Technologies

- C#
- WPF
- .NET
- REST API

## Overview

The project explores the development of a desktop client for interacting with a document management system.

It combines API communication with a graphical interface for presenting and organizing document-related information.

## Features

The application includes components for:

- Displaying document-related information
- Presenting a dashboard
- Viewing document details
- Working with tags
- Communicating with the Paperless NGX API

## Learning Objectives

The project provided practical experience with C#, WPF, desktop application development, API integration, and UI organization.

## Security

API credentials and access tokens should be configured privately and must not be committed to the repository.
